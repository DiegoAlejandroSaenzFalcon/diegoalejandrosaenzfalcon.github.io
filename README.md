## Principios del sitio

- Experiencia laboral, formación, certificaciones, conocimientos y proyectos personales se presentan por separado.
- No se atribuye experiencia laboral en TI, títulos terminados, bilingüismo ni certificaciones sin evidencia.
- Los proyectos personales demuestran aprendizaje y práctica; no se presentan como empleo ni como clientes.
- La gobernanza transversal reside en `DiegoAlejandroSaenzFalcon/Directivas-de-Seguridad`; este repositorio es una capa de presentación pública.

## Estructura

- `index.html`: página principal responsive.
- `AGENTS.md`: reglas para cambios asistidos por IA.
- `SECURITY.md` y `GOVERNANCE.md`: límites de seguridad y autoridad.
- `CI-POLICY.md` y `.github/workflows/governance-ci.yml`: validación automatizada.

## Cambios y publicación

Trabajar en ramas y Pull Requests. La CI valida; no modifica ni publica cambios mediante commits automáticos. La rama `main` no debe modificarse directamente. Una propuesta solo se considera lista después de revisar el diff y comprobar el resultado de CI.
