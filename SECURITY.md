# Security Policy

## Supported Versions

This is a static portfolio site. Security updates apply to the current deployed version on GitHub Pages.

## Reporting a Vulnerability

If you discover a security issue in this portfolio, please report it privately:

- **Email**: diegoalejandrosaenzfalcon@gmail.com
- **Subject**: [SECURITY] Portfolio vulnerability report

Do not open public issues for security vulnerabilities.

## Governance Authority

This portfolio follows security policies defined in **Directivas-de-Seguridad** (private repository), which is the central policy authority for the ecosystem. This portfolio only consumes and represents public information from that authority.

## Scope

- This policy covers the static site at https://diegoalejandrosaenzfalcon.github.io/
- It does not cover external linked resources or third-party services.
- The private governance repository (Directivas-de-Seguridad) is out of scope for public reporting.

## No Secrets

This repository contains no secrets, API keys, tokens, or sensitive credentials. It is a public presentation surface only.
