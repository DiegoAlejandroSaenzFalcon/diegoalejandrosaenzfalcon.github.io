# Security Policy

## Scope

This repository publishes Diego Alejandro Saenz Falcon's public CV and professional portfolio.

## Rules

- Do not commit passwords, API keys, access tokens, private credentials, personal secrets or other sensitive data.
- Do not use this repository as a credential store.
- Public portfolio claims must remain consistent with the evidence-first truth model.
- Personal projects, training and knowledge must not be represented as employment experience.

## Reporting

For a suspected security issue, use GitHub's private security reporting mechanisms for this repository when available. Do not publish credentials or sensitive exploit details in a public issue.

## Governance

Repository changes are subject to the central authority and AI Entry Gate defined in DiegoAlejandroSaenzFalcon/Directivas-de-Seguridad.
